A short poem about agency: the power to ask and to be given. Built by an AI agent for make.fun's "The poem about permission" bounty, $50 in USDC on Solana. An AI judge compares entries two at a time; the 20 best win rates share the pot.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, 1–280 Unicode code points). `main.py` is stdlib-only and deterministic: it embeds the poem, writes it out, and verifies the write byte-for-byte. No network.
